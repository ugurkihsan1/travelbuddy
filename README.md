# TravelBuddy desktop preview

Download this branch as a ZIP, extract it and open TravelBuddy-preview.html in Chrome or Edge. No installation or local server is required.

The bundled English interface supports itinerary settings, route planning, visiting/skipping stops and travel essentials. An offline schematic is included. Live map tiles require internet; browser location and storage depend on browser file-origin rules.

This is a generated preview of the TravelBuddy application, not a hosted web app.
