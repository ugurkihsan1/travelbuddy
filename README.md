# TravelBuddy — revised preview

Download this branch as ZIP, extract it, then double-click TravelBuddy-preview.html in a desktop browser. No installation is required. The UI is English only.

New: a vivid blue/teal/amber design, larger text, daily walking totals, 20 accommodation areas, daily starting time, adjustable coffee breaks and Google Maps route links.

53 venue photographs are embedded with author/licence/source credits in the place details. Full reuse information is in photo-attribution.json. One photo is explicitly unavailable.

Official entrance-fee snapshots are dated 8 October 2026. Seven paid venues were verified; other paid entries are labelled unavailable. Free-entry descriptions are curated general guidance. The standalone preview uses saved prices: automatic daily price/photo updates require the running venue information service in the application's source checkout. This ZIP is not an API deployment.

Use Customize my trip to change your plan. The first-run form asks the starting time. Coffee pauses shift subsequent stop times. Maps links open a separate browser tab and share the chosen route coordinates with Google.
